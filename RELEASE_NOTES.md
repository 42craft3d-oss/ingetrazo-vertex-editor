# Vertex Editor v1.1

Extensión independiente para editar un vértice de la malla activa en IngeTrazo. Esta es la primera versión preparada para publicación en este repositorio, con número `v1.1` porque incorpora mejoras sobre la versión usada inicialmente.

- Vista previa en tiempo real del movimiento y de las caras conectadas.
- Introducción de medidas exactas y bloqueo de ejes a través de IngeTrazo.
- Unión de vértices coincidentes con limpieza y rechazo de fusiones que abren nuevos bordes o aristas problemáticas.
- Cancelación con Esc, confirmación con clic o Enter y deshacer con Ctrl+Z.
- Barra Vertex independiente e icono propio.

Para instalar: descargue `vertex_editor.py`, cópielo en la carpeta que abre **Extensiones → Abrir carpeta de plugins** y reinicie IngeTrazo.

El README incluye capturas estáticas de estados independientes de la herramienta.
